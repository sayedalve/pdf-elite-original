# Third-Party Dependencies

PDF Elite relies on several excellent open-source projects. This document lists the primary third-party components and their respective licenses.

## Native C++ Components

### PDFium
- **Usage**: Core PDF parsing, rendering, and manipulation engine.
- **License**: BSD 3-Clause License (Google / Foxit)
- **Location**: \
ative/third_party/pdfium/\

### Direct2D & Windows SDK
- **Usage**: Hardware-accelerated 2D graphics rendering.
- **License**: Microsoft Windows SDK License

## Backend Java Components

### Spring Boot
- **Usage**: REST API, dependency injection, and core backend framework.
- **License**: Apache License 2.0

### PDFBox
- **Usage**: Backend PDF manipulation and utility functions.
- **License**: Apache License 2.0

## Frontend Web Components

### React
- **Usage**: Web user interface rendering framework.
- **License**: MIT License

### Vite
- **Usage**: Frontend build tooling and development server.
- **License**: MIT License

### Mantine UI
- **Usage**: React component library and UI framework.
- **License**: MIT License

### TailwindCSS
- **Usage**: Utility-first CSS framework.
- **License**: MIT License
