# Third-Party Dependencies

PDF Elite relies on the following major components for its native rendering and architecture:

## PDFium
- **Usage**: The core backend engine used for parsing, rasterizing, and serializing PDF documents.
- **License**: BSD 3-Clause License (Google / Foxit)
- **Location**: \
ative/third_party/pdfium/\

## Direct2D (Windows SDK)
- **Usage**: Used for all hardware-accelerated UI rendering, canvas overlays, and tool visualization.
- **License**: Microsoft Windows SDK License
